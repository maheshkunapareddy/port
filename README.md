# Mahesh Kunapareddy — Portfolio

A motion-driven personal portfolio built from `mahesh_portfolio.md` using plain **HTML, CSS, and JavaScript** — no build step, no dependencies.

## Live sections

- Hero with animated name reveal, rotating typewriter, and code card
- About + career objective
- Skills and toolkit
- Project concepts (honestly labelled as ideas/in progress)
- Academic focus, coursework, strengths, and learning tracks
- Education timeline
- Contact with copy-to-clipboard email

## Motion design

- Preloader with progress counter
- Scroll progress bar and active navigation
- IntersectionObserver scroll reveals with stagger
- Custom cursor with magnetic hover states
- 3D tilt + spotlight cards
- Animated constellation background (canvas)
- Infinite marquee and reduced-motion support

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Update these placeholders before publishing:

- Email: `mahesh@example.com` (in `index.html`)
- GitHub and LinkedIn URLs
- College, branch, year, and graduation year
- Project details and screenshots once projects are actually built

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and content |
| `styles.css` | Theme, layout, responsive design, motion |
